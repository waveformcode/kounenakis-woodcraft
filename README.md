# Ξυλουργείο Κουνενάκη

Στατική ιστοσελίδα, HTML, CSS και JS χωρίς frameworks.

## Πριν ανέβει
1. Domain: το `https://kounenakis.gr` είναι προσωρινό. Αν το domain είναι άλλο, άλλαξέ το
   στο `index.html` (canonical, og:url, og:image, JSON-LD), στο `robots.txt` και στο `sitemap.xml`.
2. Χάρτης: όταν φτιαχτεί το προφίλ Google, βάλε το embed του στο `index.html` (σχόλιο ΧΑΡΤΗΣ).
3. Fonts: άλλαξε `--font-head` και `--font-body` στο `assets/css/styles.css`.

## Μετά το ανέβασμα
- Google Search Console: πρόσθεσε το site και κάνε υποβολή του `sitemap.xml`.
- Google Business Profile: κατηγορία "Ξυλουργός", ίδιο όνομα και ίδια περιοχή με το site,
  και στο πεδίο "Ιστότοπος" βάλε τη διεύθυνση του site.
